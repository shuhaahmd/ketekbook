# KetekBook

A web-based sports court booking system designed to simplify court reservations and facility management.

## Features

- Browse available sports courts
- Book courts without creating an account
- Flexible booking durations
- Automatic booking confirmation
- Booking reference and summary
- Admin dashboard for booking management
- Manage courts, rates, and operating hours
- Block unavailable time slots
- Real-time booking updates for administrators

## Technologies Used

- Next.js
- React
- JavaScript
- Supabase
- PostgreSQL
- CSS

## Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd ketekbook
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env.local` file in the project root:

```env
NEXT_PUBLIC_SUPABASE_URL=YOUR_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=YOUR_SUPABASE_PUBLISHABLE_KEY
```

### 4. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
